## MyCat v0.5.0

原生 macOS 照片定制 Q 版桌宠，macOS 14+，支持 Apple Silicon 和 Intel。

- 公开版只包含程序绘制的通用示例猫，不包含用户照片、衍生图像或相关历史。
- 修复高速按键下的瞬间切帧：改为约 300 ms 的完整抬爪/落爪周期，连续打字合并为可读动作。
- 真实鼠标按下/松开事件触发下压、变色与点击光圈，长按保持状态。
- 60 Hz 绘制与按实际经过时间推进动画；24–120 Hz 时间一致性测试。
- 新增 30 秒合成输入演示、实际输入诊断，以及键盘互动选择的持久化。
- 可用自己的照片和 API Key 生成 Q 版动作图，支持流式草稿预览；只有确认应用后替换。
- 日常运行离线，不读取具体键码/文字，不保存输入记录。

下载 **MyCat-macOS-universal.zip**，解压后将 MyCat.app 放入“应用程序”。

启用键盘互动后，需在系统设置 → 隐私与安全性 → 输入监控授权。下载包采用 ad-hoc 签名，尚未通过 Apple 公证。macOS 可能要求在“隐私与安全性”中允许打开。

自动测试包含 30 秒/300 次按键回放与本机模拟 API；真实 API 生成需要用户自己的有效额度，尚未做付费端到端验证。
