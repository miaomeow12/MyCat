# 数据与权限

本私有分享版包含主人明确授权的 Q 版动作图与衍生演示；不包含原始照片或 API Key。内置形象保存在应用 Resources 中，获得安装包的人可以提取、保存；仓库与下载仅供获授权的私有访问。

## 本地陪伴

键盘使用 `CGEvent.tapCreate(... options: .listenOnly)`，只订阅 `keyDown`。回调不读取事件中的键码、字符、修饰键，事件原样返回；没有拦截、修改或发送真实按键。

鼠标位置使用 `NSEvent.mouseLocation`；点击使用 `NSEvent` 的本应用/全局只读监听器，读取按钮编号与按下/松开状态。仅驱动动画，不控制真实指针。

输入诊断中的累计次数只存内存，不记录时间序列或输入内容。退出时销毁所有监听器。键盘开关保存在系统 UserDefaults，已选择开启后下次启动会尝试连接；没有授权时不会伪装为连接成功。

不申请辅助功能、屏幕录制、摄像头或麦克风权限。密码框、安全输入或受保护应用中的键盘事件可能不可用。

## 可选的 API 生成

只有用户选择照片、填写自己的 Key 并点击“上传并生成”时才请求 `https://api.openai.com/v1/images/edits`。

照片先在本机缩放并转为 PNG，再随提示词发送。没有本项目运营的服务器。

- Key 只用于本次 HTTP Authorization；输入框在开始请求时清空，关闭窗口也清空。
- 不把 Key 写入文件、UserDefaults、仓库或生成提示词。
- 使用临时 URLSession，禁用磁盘 URL 缓存、Cookie、重定向。
- 草稿只用于窗口预览，只有最终图片且用户点击“应用”后才保存和替换桌宠。
- 不自动重试付费请求。取消本机等待不保证服务端不计费。
- 服务提供方的数据政策仍适用于你上传的照片，参见 [OpenAI API 数据控制](https://platform.openai.com/docs/guides/your-data)。

## 本地文件

`~/Library/Application Support/MyCatLocal/`：

- `cat.png`：本地处理后的真实照片。
- `companion.png`：当前应用的 Q 版动作图。
- `companion-<UUID>.png`：生成图的保留副本。

“删除原照片”只删除 `cat.png`。退出应用后删除该目录可移除所有自定义图像。系统输入监控授权可在系统设置里撤销。

没有统计上报、自动更新或输入日志。

## 测试边界

输入自动化回放使用合成事件直接调用本程序回调，不向其他应用注入输入。演示画面明确标注“演示中”，不作为真实 OS 监听已授权的证明。

图片 API 的自动化回归使用本机模拟协议拦截全部请求，包括分块 SSE 预览、最终完成、HTTP 401、断流和生成失败。未使用真实 Key 做付费端到端验证。模型生成图片的语义正确性、猫的相似度和动作格子仍需用户查看预览。
